#### 1) Список лексем с номерами номерами, обозначениями и значениями лексем.

    **Лексемы, выделяемые лексическим анализатором:**
    - Имена (идентификаторы)

#### 4) Семантические действия для генерации ОПС
- □ - пустое действие;

- a - записать в ОПС ссылку на переменную (имя из таблицы переменных);

- k - записать в ОПС ссылку на константу (целое число);

- +, -, *, / - записать в ОПС бинарную арифметическую операцию;

- -' - записать операцию «унарный минус»;

- <, >, <=, >=, =, <> - записать операцию сравнения;

- i - записать операцию индексации одномерного массива;

- := - записать операцию присваивания;

- r - записать операцию чтения (read);

- w - записать операцию вывода (write);

- 1, 2, 3, 4, 5 - выполнить семантическую программу генерации меток и переходов.

##### Семантические программы
- Программа 1 (условный переход по false):
    * Записать k в магазин меток.
    * Записать в ОПС пустой элемент (место для будущей метки).
    * Записать в ОПС операцию jf.

- Программа 2 (безусловный переход в else):
    * Через верх магазина меток записать k+2 в ранее заготовленное место для метки.
    * Записать k в магазин меток.
    * Записать в ОПС пустой элемент.
    * Записать в ОПС операцию j.

- Программа 3 (завершение метки после else):
    * Через верх магазина меток записать текущее k в заготовленное место.

- Программа 4 (сохранение метки начала цикла):
    * Записать k в магазин меток.

- Программа 5 (переход на начало цикла):
    * Через верх магазина меток записать k+2 в место для метки выхода.
    * Записать в ОПС метку, взяв её значение из магазина меток (метка начала).
    * Записать в ОПС операцию j.

#### 5) Список операций ОПС

+ - Бинарное сложение
- - Бинарное вычитание
* - Бинарное умножение
/ - Бинарное деление (с плавающей точкой)
-' - Унарный минус (смена знака)
< - Сравнение «меньше» (результат: true или false)
> - Сравнение «больше»
<= - Сравнение «меньше или равно»
>= - Сравнение «больше или равно»
= - Сравнение «равно»
<> - Сравнение «не равно»
i - Индексация одномерного массива: по ссылке на массив и индексу вычисляет ссылку на элемент
:= - Присваивание: первый операнд - ссылка на переменную/элемент, второй - значение
r - Чтение целого числа со стандартного ввода. Операнд — ссылка на переменную, в которую заносится прочитанное значение
w - Вывод значения в стандартный вывод. Операнд — целое число (значение выражения)
jf - Условный переход: если первый операнд false, передать управление на элемент ОПС с номером, заданным вторым операндом
j - Безусловный переход: передать управление на элемент ОПС с номером, заданным операндом

#### 6) Формат ОПС

ОПС (обратная польская запись) — это промежуточное представление программы в виде последовательности элементов.

**Типы элементов ОПС:**

| Тип | Описание | Пример |
|-----|----------|--------|
| Адрес переменной | Ссылка на переменную по имени | `x` |
| Константа | Целое или вещественное число | `42`, `3.14` |
| Арифметическая операция | +, -, *, /, -' (унарный минус) | `+` |
| Операция присваивания | := | `:=` |
| Индексация массива | [] | `i` |
| Операции сравнения | <, >, <=, >=, =, <> | `<` |
| Условный переход | jf (jump if false) | `jf` |
| Безусловный переход | j (jump) | `j` |
| Ввод | read | `read` |
| Вывод | write | `write` |

**Пример ОПС для выражения `x = (y + 10) * 2`:**

```
x  y  10  +  2  *  :=
```

**Пример ОПС для условия `if (a < b) { write(a); }`:**

```
a  b  <  jf  k1  a  write  j  k2
```
(где k1, k2 — позиции меток, вставляемые при генерации ОПС)


#### 6) Формат ОПС

| Роль элемента | ERPType (основные представители) |
|--------------|----------------------------------|
| Адрес (переменная) | `A_VariableName` |
| Константа (число/строка/bool) | `A_Number`, `A_TextLine`, `A_Boolean` |
| Операция (арифм., логич., присв.) | `F_Plus`, `F_Minus`, `F_Multiply`, `F_Divide`, `F_Modulus`, `F_Equal`, `F_Less`, `F_Greater`, `F_LessEqual`, `F_GreaterEqual`, `F_And`, `F_Or`, `F_Not`, `F_Assignment` |
| Метка (для переходов) | `M_Mark` | `RPNMark` |
| Условный переход по лжи (УПЛ) | `F_ConditionalJumpToMark` |
| Безусловный переход | `F_UnconditionalJumpToMark` |
| Индексация массива | `F_Index` |
| Встроенная функция ввода/вывода | `F_Output`, `F_Input` |
| Встроенная математическая функция | `F_Sqrt`, `F_Pow` |
| Объявление переменной | `F_Int`, `F_String`, `F_Bool` |
| Объявление массива | `F_IntArray`, `F_StringArray`, `F_BoolArray` |


```cpp
#include "RPNSymbol.h"
#include <vector>
#include <memory>

using namespace Compiler;
using namespace std;

vector<unique_ptr<RPNSymbol>> buildExample1() {
    // x = (y + 10) * 2;
    vector<unique_ptr<RPNSymbol>> rpn;

    // адреса (переменные)
    auto x = make_unique<RPNIdentifier>(ERPNType::A_VariableName);
    x->Name = "x";
    auto y = make_unique<RPNIdentifier>(ERPNType::A_VariableName);
    y->Name = "y";

    // константы
    auto k10 = make_unique<RPNNumber>(ERPNType::A_Number);
    k10->Data = 10;
    auto k2 = make_unique<RPNNumber>(ERPNType::A_Number);
    k2->Data = 2;

    rpn.push_back(move(x));                                        // a: переменная x (цель присваивания)
    rpn.push_back(move(y));                                        // a: переменная y
    rpn.push_back(move(k10));                                      // k: 10
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_Plus));       // O: +
    rpn.push_back(move(k2));                                       // k: 2
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_Multiply));   // O: *
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_Assignment)); // O: =

    return rpn;
}

vector<unique_ptr<RPNSymbol>> buildExample2() {
    // if (a < b) { output(a); }
    vector<unique_ptr<RPNSymbol>> rpn;

    auto a = make_unique<RPNIdentifier>(ERPNType::A_VariableName);
    a->Name = "a";
    auto b = make_unique<RPNIdentifier>(ERPNType::A_VariableName);
    b->Name = "b";

    // условие
    rpn.push_back(move(a));
    rpn.push_back(move(b));
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_Less));    // O: <

    // метка для перехода при ложном условии
    auto ifMark = make_unique<RPNMark>(ERPNType::M_Mark, EMarkType::IfMark);
    // позиция будет установлена позже
    rpn.push_back(move(ifMark));                                // m: метка
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_ConditionalJumpToMark)); // УПЛ

    // тело if: output(a)
    auto a2 = make_unique<RPNIdentifier>(ERPNType::A_VariableName);
    a2->Name = "a";
    rpn.push_back(move(a2));                                    // a
    rpn.push_back(make_unique<RPNSymbol>(ERPNType::F_Output));  // f: write

    // теперь фиксируем позицию метки (конец блока if)
    // в реальном коде это делает RPNTranslator::WriteMarks
    size_t labelPos = 3; // индекс, где лежит RPNMark
    auto* mark = static_cast<RPNMark*>(rpn[labelPos].get());
    mark->Position = rpn.size();   // метка указывает на позицию сразу за последней операцией

    return rpn;
}
```
